TFR 长征智能对话系统

基于 Streamlit + DeepSeek API 打造的《钢铁雄心 4》TFR 模组「人工智能统辖・长征」沉浸式对话应用，全程保持角色人格，附带完整的本地会话管理体系。

 核心功能

- 沉浸式角色扮演：严格遵循长征人设，以理性、克制的统辖者视角回应所有话题
- 流式实时输出：支持流式生成回复，内置深度思考模式
- 自动会话归档：每轮对话自动本地保存，无需手动操作
- 历史会话管理：侧边栏支持加载、删除历史记录，删除带二次确认
- 定制化视觉：专属角色立绘、动效与深色主题 UI

快速开始

1. 安装依赖

```
pip install streamlit openai pillow
```

2. 配置 API 密钥
设置系统环境变量 `DEEPSEEK_API_KEY` 为你的 DeepSeek API Key。
3. 启动项目

```
streamlit run main.py
```

说明

- 历史会话默认保存在 `AI大模型调用/sessions/` 目录下
